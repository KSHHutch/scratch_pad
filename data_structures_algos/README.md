# Algorithms
## Bubblesort
- Largest values, "bubble up" through the array
- Check a value with its neighbor on the right.  If the value is bigger, swap their spots.  Rinse repeat for element of the array until no more swaps are made
## Quicksort
- Method for sorting an array
- Main idea: Recursive algorithm.  
  - Pivots off of an array element
  - Moves everything bigger than that element to its right and everything smaller to its left
  - Change out the pivot element to be the first element of the bigger side sub-array
